# VAJRA — AI-Based Intelligent Video Analytics Platform

## Project Overview

**VAJRA** is a student-built intelligent video surveillance prototype developed for **SIH 26187 — AI-Based Intelligent Video Analytics Platform for Border Surveillance using Existing CCTV Infrastructure**.

The platform brings CCTV monitoring, intelligent video-analysis concepts, alerts, reports, authentication and system controls into a single tactical dashboard.

## Project Architecture

The system is organized into a React-based frontend, Node.js/Express backend, CCTV media, surveillance data and reusable interface components.

## Key Features

- CCTV video monitoring
- Human detection
- Vehicle analytics
- Face detection
- ANPR
- Virtual fence monitoring
- Suspicious activity monitoring
- Night movement monitoring
- Alerts and event logs
- Biometric verification interface
- Reports and visualization
- Settings and system management

## Project Goals

- Use existing CCTV infrastructure as the foundation for surveillance.
- Present surveillance information through one centralized interface.
- Demonstrate AI-based video analytics concepts in a student-friendly prototype.
- Provide a modular structure that can be expanded with real CCTV streams and production AI models.

## Current Status

The uploaded VAJRA prototype contains the main authentication flow, CCTV monitoring interface, surveillance videos, surveillance data, settings interface and Node.js/Express backend structure.

> **Note:** The current project is a prototype. Real operational CCTV integration and production AI inference are future expansion areas.
