# VAJRA SIH 26187 - Complete Documentation Website

This is a single documentation website for Team HEXAVAULT.

## Pages

1. Home
2. System Overview
3. Project Summary
4. Project Architecture
5. References

## Website UI

Material for MkDocs provides:

- Top search bar
- Left-side page navigation
- Main content
- Automatic right-side Table of Contents
- Search suggestions
- Search highlighting
- Clickable headings
- Code-copy buttons

## Netlify Deployment

Build command:

```text
pip install mkdocs-material && mkdocs build
```

Publish directory:

```text
site
```

## Local Test

```bash
pip install mkdocs-material
mkdocs serve
```
